Add a phone camera

…
  1. Put the phone on the same Wi-Fi as this computer.
  2. Scan the code with the phone camera, or type the address.
  3. First time only, the phone warns the link is not private. It is your own computer, so tap Advanced → Proceed (Android) or Show Details → visit this website (iPhone).
  4. Name the camera, tap Start camera and allow the camera.

Put a phone in OBS

  1. Click Copy OBS link on the camera.
  2. In OBS, Sources + → Browser, name it after the camera.
  3. Paste the link into URL, set Width 1920 and Height 1080.
  4. Leave Shutdown source when not visible and Refresh browser when scene becomes active unticked. Click OK.

Same phone in another scene: Sources + → Browser → Add Existing. One source per phone.

The phone shows a red frame when its camera is on Program (live) and a green frame when it is not.

Put a phone in vMix

  1. Click Copy vMix link on the camera.
  2. In vMix, Add Input → Web Browser, paste the link.
  3. Set the size to 1920 × 1080.

vMix shows the picture. The red/green light on the phone works with OBS for now.
